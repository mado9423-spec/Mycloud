# الموسسة — نموذج أولي (غير رسمي)

تطبيق ويب عربي RTL متجاوب لعرض الأخبار العامة وإعلانات ومواعيد الالتحاق ومتطلبات التقديم، مع واجهة استكشاف تخصصات ومتابعة طلب افتراضي.

> **تنبيه:** هذا نموذج أولي مستقل غير رسمي. لا يتبع القوات المسلحة الليبية أو أي جهة حكومية. كل المحتوى والمواعيد والأرقام تجريبية للعرض فقط.

## التشغيل

```bash
cd almoasasa
pnpm install
pnpm dev        # وضع التطوير
pnpm typecheck  # فحص TypeScript
pnpm build      # بناء نسخة الإنتاج
pnpm preview    # معاينة نسخة الإنتاج محلياً
```

## التقنيات

- React 18 + TypeScript + Vite
- Tailwind CSS v4 (عبر @tailwindcss/vite)
- React Router v7 (HashRouter — مناسب للاستضافة الثابتة)

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | الرئيسية: إعلان بارز، أحدث الأخبار، أقرب موعد تجريبي، اختصارات |
| `/news` | أخبار تجريبية: بحث، تصنيفات، تاريخ نشر ومصدر لكل بطاقة |
| `/opportunities` | فرص وتخصصات عامة بتصفية حسب الحالة + مدقق أهلية توضيحي |
| `/dates` | مواعيد تجريبية بتمييز القادم/المنتهي |
| `/steps` | خطوات تقديم إرشادية + قائمة تحقق مستندات (عامة فقط) |
| `/track` | متابعة طلب تجريبي برقم مرجعي وهمي ومراحل توضيحية |
| `/faq` | أسئلة شائعة |
| `/contact` | بيانات تواصل placeholder + نموذج مراسلة معطّل |
| `/admin` | لوحة إدارة شكلية لمحرر محتوى (بدون مصادقة أو نشر فعلي) |

## ما هو تجريبي بالكامل

- كل الأخبار والإعلانات والمواعيد والفرص والشروط والأرقام المرجعية وبيانات التواصل.
- مدقق الأهلية: أسئلة عامة داخل الواجهة فقط، لا يُخزّن أو يُرسل أي شيء.
- قائمة تحقق المستندات: تحديد توضيحي داخل الواجهة، لا يوجد رفع ملفات فعلي.
- لوحة الإدارة: تحرير في حالة العرض فقط، بدون مصادقة أو نشر أو حفظ دائم.
- نموذج المراسلة: معطّل ولا يرسل أي رسالة أو إشعار.

## ما يحتاج اعتماداً أو ربطاً آمناً قبل أي إطلاق فعلي

1. موافقة رسمية من الجهة المسؤولة ومصدر محتوى معتمد (لا جلب آلي من مصادر غير موثقة).
2. مراجعة قانونية وأمنية + سياسة خصوصية معتمدة.
3. خادم مؤمّن، نظام مصادقة وصلاحيات محددة، وسجل تدقيق.
4. استبدال كل بيانات placeholder بقنوات رسمية معتمدة.
5. تفعيل وظائف التقديم/المرفقات/الإشعارات عبر أنظمة معتمدة فقط، وبأقل قدر من البيانات.

## ملاحظات أمان

- التطبيق لا يجمع أي بيانات شخصية ولا يستخدم تحليلات أو تتبعاً.
- لا يحتوي أي معلومات عملياتية أو مواقع وحدات أو خطط أو تفاصيل تدريب أو أسلحة.
- فئات الشروط المعروضة عامة واسترشادية من شكل إعلانات القبول العامة المنشورة عبر وكالة الأنباء الليبية (lana.gov.ly)، ولا تُعد شروطاً رسمية معتمدة.
