# المؤسسة - تطبيق ويب معلوماتي

## وصف المشروع

**المؤسسة** هو تطبيق ويب عربي RTL متجاوب يهدف إلى تقديم معلومات توضيحية حول إجراءات الالتحاق بالبرامج التدريبية. هذا التطبيق هو **نموذج أولي غير رسمي** وغير تابع لأي جهة حكومية.

## الميزات

### واجهة المستخدم
- ✅ تصميم عربي كامل بدعم RTL
- ✅ متجاوب مع جميع أحجام الشاشات (Mobile-first)
- ✅ تصميم حديث حسب Apple Human Interface Guidelines
- ✅ تأثيرات Glassmorphism و Squircle
- ✅ حركات سلسة و أنيميشن خفيفة

### الصفحات الرئيسية
- 🏠 **الصفحة الرئيسية**: عرض إعلان بارز، آخر الأخبار، الفرص المفتوحة، المواعيد القادمة
- 📰 **الأخبار**: قائمة بالأخبار مع تصنيفات وبحث وتاريخ نشر
- 🎯 **فرص الالتحاق**: عرض التخصصات والفرص المتاحة مع تصفية
- 📅 **المواعيد**: تقويم/قائمة بمواعيد الاختبارات والتدريبات
- 📋 **خطوات التقديم**: دليل تفصيلي لخطوات التقديم
- 🔍 **متابعة الطلب**: نظام متابعة الطلبات برقم مرجعي وهمي
- ❓ **الأسئلة الشائعة**: قائمة بالأسئلة والإجابات الشائعة
- 📞 **تواصل معنا**: معلومات الاتصال ونموذج اتصال توضيحي
- 🛠️ **لوحة الإدارة**: واجهة لإدارة المحتوى (تجريبية)

## التقنية المستخدمة

- **Frontend**: React 18 + TypeScript
- **Routing**: React Router DOM v7
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Bundler**: Vite

## المتطلبات

- Node.js 18+
- pnpm (مفضل) أو npm أو yarn

## التثبيت والتشغيل

### 1. استنساخ المشروع

```bash
git clone https://github.com/mado9423-spec/Mycloud.git
cd Mycloud/almoasasa
```

### 2. تثبيت التبعيات

```bash
pnpm install
# أو
npm install
```

### 3. تشغيل التطبيق

```bash
pnpm dev
# أو
npm run dev
```

سيتم فتح التطبيق على `http://localhost:5173`

### 4. بناء للإنتاج

```bash
pnpm build
# أو
npm run build
```

### 5. معاينة البناء

```bash
pnpm preview
```
